## 3. Completeness: two flagged gaps, not silently fixed

**Gap 1, Code Connect drift (`src/components/Fab.figma.tsx`).** The mapping's `Variant` enum key `Circular` does not match the live component set's real property option, which is named `Round`. Its `Color` enum lists `Error`, `Success`, `Info`, and `Warning`, none of which have a live Figma variant to bind to (see Gap 2). Fixing the Code Connect file itself was out of scope this pass (only the Figma canvas, its tokens, and `brandTheme.ts` were asked for); flagging the exact mismatch here so a future pass can correct the mapping once the missing color variants (or a renamed `Variant` option) are decided.

**Gap 2, missing `Error`/`Success`/`Info`/`Warning` Figma variants.** MUI's real `Fab` code genuinely supports these four colors today, verified directly against `Fab.js`'s generic palette-loop mechanism, the same one Button uses. Figma's live `<Fab>` set simply has never had these variants built. **Logged as a product gap for design to pick up as its own dedicated pass** (build the four color variants against the same grid, then re-run this token migration against the richer set), the same pattern already used for Drawer's missing anchor/variant axis and Backdrop's own earlier Style x Visibility gap.

Both gaps are structural (a missing variant, a mismatched enum key), not token-hygiene issues, and neither was silently patched over.
